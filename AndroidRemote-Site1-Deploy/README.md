Android Remote site deployment bundle

Target repository: https://github.com/brimiomxf-arch/android-remote-site1
Expected GitHub Pages URL: https://brimiomxf-arch.github.io/android-remote-site1/

Contents
- index.html: Arabic/English landing and download page
- ReceiverControl-Controller.apk: phone app
- ReceiverControl-Receiver.apk: receiver app
- .github/workflows/pages.yml: deploys the root folder to GitHub Pages on pushes to main

After uploading these files to the main branch, set Repository Settings > Pages > Build and deployment > Source to GitHub Actions if Pages is not already enabled.

The Downloader direct APK URL is formed by the page from its live URL. The numeric Downloader code remains to be added after it is generated at go.aftvnews.com; it requires completing that site's CAPTCHA.
