# Android remote + Android TV responsiveness

Native Android project written in Kotlin and Jetpack Compose. It contains two independent APKs:

- `controller`: phone app for remote control, network discovery, pairing, files, apps, screen preview, settings, and ADB.
- `receiver`: optional companion app for Android TV / receiver. It hosts the local TCP/UDP service used for advanced features.

## Two connection methods

### Direct Android TV Remote (no companion app)

Use **Devices > Search Wi-Fi**. The phone looks for the `_androidtvremote2._tcp.` DNS-SD service. Select the Android TV device, start pairing, approve the pairing request on the TV, and enter the six-character code shown by the TV. The protocol uses Android TV Remote v2 pairing and remote ports (6467 and 6466). This works only on Android TV devices that expose this service and allow remote pairing. It supports the basic remote keys; apps, files, JSON, and screen preview need the companion app or ADB.

### ReceiverControl companion app (7-digit code)

Install and open **Android TV responsiveness** on the receiver, start its connection service, then pair from the phone with its QR code or seven-digit code. The receiver app announces itself over UDP on port 39000 and accepts framed JSON/TCP commands and file transfers on port 39001. This path provides the app-specific features: app listing and launch/uninstall, file transfer, custom JSON, and screen snapshots. Accessibility permission may be required for some system actions and screen capture.

The two codes are different: the six-character code is shown by a compatible TV during native pairing; the seven-digit code is generated by the optional companion app. Do not enter one code in the other mode.

### UrTV phone remote

Install UrTV on the TV, open **Phone control > Start**, and keep that screen open. In **Devices**, enter the TV's private IPv4 address; Android remote searches UrTV's temporary local port and opens the remote page served by the TV inside the app. The page is not copied into this project. UrTV's short-lived pairing code/QR and approval on the TV remain required.

## Main features

- Remote UI inspired by the open-source Android TV Remote project: D-Pad, touch pad, channel/volume controls, and number pad.
- Wi-Fi discovery for native Android TV Remote devices and the optional ReceiverControl service. DNS-SD discovery intentionally targets the Android TV remote service; generic Chromecast, AirPlay, DLNA, printers, or arbitrary IP devices do not automatically become controllable remotes.
- Separate native pairing and companion pairing screens with clearer rejection, timeout, and network errors.
- App and media sections, file transfer, screen snapshots, and picture-in-picture preview over the companion app or ADB.
- Hidden ADB controls under Settings, ten editable favorites, Arabic/English, and light/dark purple-gray themes.
- App names and icons: `Android remote` for the phone controller and `Android TV responsiveness` for the receiver app.

## Build in Android Studio

Open the `ReceiverControlAndroid` folder in Android Studio. Use JDK 17, Android SDK Platform 37, and the Gradle wrapper. Select the `controller` or `receiver` run configuration, or run:

```powershell
./gradlew.bat :controller:assembleDebug :receiver:assembleDebug
```

The debug APKs are written to each module's `build/outputs/apk/debug/` folder. Install the controller APK on the phone. Install the receiver APK only if you need companion features.

## Editing the app

- Compose screens and styling: `controller/src/main/java/com/monib/receivercontrol/controller/ControllerUi.kt` and `receiver/src/main/java/com/monib/receivercontrol/receiver/ReceiverDashboard.kt`.
- Connection and pairing: `LanClient.kt`, `AndroidTvDiscovery.kt`, `AndroidTvRemoteClient.kt`, and `receiver/.../LocalReceiverService.kt`.
- App behavior and state: `controller/.../MainActivity.kt` and `receiver/.../MainActivity.kt`.
- Icons and branding: module `src/main/res/` and the `branding/` folder.

Open any Kotlin source in Android Studio or VS Code. After editing, sync Gradle and rebuild the APK. Update tests on a real compatible Android TV for native pairing; use the companion app on a second device for the extended feature set.

## Editing the website

Edit `website/index.html`. The published copy is `AndroidRemote-Site1-Deploy/index.html` in the GitHub repository. Keep the APK links and Downloader code (`9187062`) aligned with the APK files. Push changes to `main`; the Pages workflow publishes the deployment folder automatically.

## ADB and platform limitations

ADB is an advanced option under Settings. It uses network ADB TCP (commonly port 5555) and requires the receiver to enable debugging and approve the phone's RSA key. Wireless Debugging pairing on a temporary pairing port is not implemented.

An ordinary app cannot silently inject every system key, turn on a sleeping TV, or capture protected content. Use the native remote service, enable the receiver's Accessibility service where requested, or connect with ADB. Screen preview consists of periodic screenshots rather than continuous video; secure apps may return a blank image. App launch or uninstall can also be restricted by Android background rules and system confirmation dialogs.
